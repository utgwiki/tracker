Bartholomew announces Roblox game visit milestones and updates to Discord every 3 minutes, and offers various features:

| Feature | Description |
|---|---|
| **Visit Milestone Announcements** | Get notified every X visits (configurable). |
| **Game Update Alerts** | Receive notifications when your game is updated. |
| **Subplace Detection** | Notifies you when new subplaces are added to the game. |
| **Multiple Game Support** | Track multiple Roblox games with a single bot instance. |

**Please read [the wiki](https://github.com/utgwiki/bartholomew/wiki) for documentation :-)**
